# 胡桃（Hutao）桌面皮肤 · PC 版

Windows 专属悬浮皮肤。窗口**始终置顶、透明无边框**，悬浮于任何应用之上——因此 VSCode、PyCharm、Trae-IDE、WebStorm、claude-code、CodeX、kimi-code、DeepSeek Harness 等所有编辑器/终端/网页**无需任何插件即可叠加使用**。

## 使用

1. 双击 `启动-胡桃皮肤.bat`（或右键 → 发送到 → 桌面快捷方式）。
2. 右下角出现胡桃皮肤挂件（宽 320px，高度按当前壁纸比例自动贴合，完整显示不裁切）：
   - **左键点击** → 释放元素爆发「安神秘法」：播放中文语音「吃饱喝饱，一路走好！」+ 赤焰闪光/血梅绽放/冲击波/三道火光/火星/字幕动画
   - **左键拖动** → 移动位置
   - **右键** → 菜单：释放元素爆发 / **切换壁纸（其一/其二/其三）** / 收起皮肤 / 开机自启 / 一键卸载 / 退出
3. 收起后变为“胡桃 ✦”胶囊（同样可拖动、右键菜单含**一键卸载**）。

## 一键卸载

胶囊或皮肤上**右键 → 一键卸载 → 确认**：关闭程序、移除开机自启、延迟 2 秒后自动删除本桌面版文件夹，无任何残留。

## 开机自启

右键菜单勾选「开机自启」：写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`（当前用户，无需管理员）。取消勾选即移除。

## 自定义

- 换壁纸：替换 `素材\胡桃-web.jpg` / `胡桃-壁纸2-web.jpg` / `胡桃-壁纸3-web.jpg`（建议 700px 左右竖版，比例自适应）。
- 换语音：把任意 mp3/ogg 用 ffmpeg 转成 WAV 覆盖 `素材\语音-元素爆发·其一.wav`：
  `ffmpeg -i 新语音.mp3 -ar 44100 -ac 1 -c:a pcm_s16le 语音-元素爆发·其一.wav`
- 改宽度：编辑 `胡桃皮肤.ps1` 开头的 `$script:CARD_W`（默认 320）。
